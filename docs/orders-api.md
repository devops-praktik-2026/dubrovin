# Договорённость о поведении сервиса заказов (orders-api)

Документ описывает три запроса HTTP-API сервиса `orders`:

1. `POST /orders` — создать заказ;
2. `GET /orders/{id}` — получить заказ по номеру;
3. `GET /orders?account_id=` — список заказов клиента.

Для каждого запроса однозначно указаны: что приходит (входные параметры),
что возвращается (структура ответа и HTTP-код) и возможные ошибки с кодами.

Общие правила:

- Все тела запросов и ответов — JSON (`Content-Type: application/json`).
- Номера (`id`, `account_id`) — целые положительные числа.
- Поле `item` — непустая строка (название заказа).
- Поле `quantity` — целое число, не меньше 1.
- Поле `created_at` — время создания заказа в формате ISO 8601 (UTC),
  например `2026-09-27T10:15:30Z`.
- Тело ответа с ошибкой содержит поле `detail` — человекочитаемое
  объяснение ошибки; для 422 дополнительно указывается проблемное поле.

Карточка заказа — эталонная структура, возвращаемая сервисом:

```json
{
  "id": 1,
  "account_id": 42,
  "item": "coffee",
  "quantity": 2,
  "created_at": "2026-09-27T10:15:30Z"
}
```

---

## 1. POST /orders — создать заказ

### Что приходит (тело запроса)

| Поле         | Тип    | Обязательное | Правила                                                |
|--------------|--------|--------------|--------------------------------------------------------|
| `account_id` | число  | да           | Номер клиента, положительное целое число               |
| `item`       | строка | да           | Что заказали; непустая строка                          |
| `quantity`   | число  | да           | Сколько; целое число, не меньше 1                      |

Пример тела запроса:

```json
{
  "account_id": 42,
  "item": "coffee",
  "quantity": 2
}
```

### Что возвращается

- **HTTP 201 Created** — карточка созданного заказа:

| Поле         | Тип    | Описание                                    |
|--------------|--------|---------------------------------------------|
| `id`         | число  | Присвоенный номер заказа                    |
| `account_id` | число  | Номер клиента из запроса                    |
| `item`       | строка | Название заказа из запроса                  |
| `quantity`   | число  | Количество из запроса                       |
| `created_at` | строка | Время создания заказа, ISO 8601 (UTC)       |

Пример ответа (201):

```json
{
  "id": 1,
  "account_id": 42,
  "item": "coffee",
  "quantity": 2,
  "created_at": "2026-09-27T10:15:30Z"
}
```

### Возможные ошибки

| Код HTTP | Когда возникает                                                                 | Тело ответа (пример)                                             |
|----------|----------------------------------------------------------------------------------|-------------------------------------------------------------------|
| 422      | Нет обязательного поля (`account_id`, `item` или `quantity`) либо `quantity` < 1 | `{"detail": "quantity must be at least 1", "field": "quantity"}`  |
| 404      | Клиента с таким `account_id` нет (проверка через сервис клиентов)                | `{"detail": "account 42 not found"}`                              |

Примечание: проверка существования клиента выполняется обращением к сервису
`accounts`; при отсутствии клиента заказ **не создаётся**.

## 2. GET /orders/{id} — получить заказ по номеру

### Что приходит (входные параметры)

| Параметр | Где          | Тип   | Обязательный | Правила                                  |
|----------|--------------|-------|--------------|------------------------------------------|
| `id`     | путь запроса | число | да           | Номер заказа, положительное целое число  |

Пример запроса: `GET /orders/1`

Тело запроса отсутствует. Других параметров нет.

### Что возвращается

- **HTTP 200 OK** — карточка заказа (та же структура, что и у `POST /orders`):
  `id`, `account_id`, `item`, `quantity`, `created_at`.

Пример ответа (200):

```json
{
  "id": 1,
  "account_id": 42,
  "item": "coffee",
  "quantity": 2,
  "created_at": "2026-09-27T10:15:30Z"
}
```

### Возможные ошибки

| Код HTTP | Когда возникает                                                        | Тело ответа (пример)                        |
|----------|-------------------------------------------------------------------------|----------------------------------------------|
| 404      | Заказа с таким номером нет                                              | `{"detail": "order 1 not found"}`            |
| 422      | `id` в пути не является положительным целым числом (например, `/orders/abc`) | `{"detail": "id must be a positive integer", "field": "id"}` |

Примечание: сообщение об ошибке 404 обязательно содержит номер, который искали.

## 3. GET /orders?account_id= — список заказов клиента

### Что приходит (параметры запроса в строке запроса)

| Параметр     | Тип   | Обязательный | Правила                                                          |
|--------------|-------|--------------|------------------------------------------------------------------|
| `account_id` | число | да           | Номер клиента, положительное целое число                         |
| `limit`      | число | нет          | Максимальное число заказов в выдаче; целое от 1 до 100; по умолчанию 20 |

Пример запроса: `GET /orders?account_id=42&limit=10`

Тело запроса отсутствует.

### Что возвращается

- **HTTP 200 OK** — объект со списком заказов только этого клиента:

| Поле  | Тип   | Описание                                                             |
|-------|-------|----------------------------------------------------------------------|
| `items` | массив | Список карточек заказов клиента (структура карточки — как выше); пустой массив, если заказов нет |

Пример ответа (200):

```json
{
  "items": [
    {
      "id": 1,
      "account_id": 42,
      "item": "coffee",
      "quantity": 2,
      "created_at": "2026-09-27T10:15:30Z"
    }
  ]
}
```

Заказы других клиентов в выдачу не попадают никогда. У клиента без заказов
возвращается **200** и пустой список (`{"items": []}`), а не ошибка.

### Возможные ошибки

| Код HTTP | Когда возникает                                                            | Тело ответа (пример)                                              |
|----------|------------------------------------------------------------------------------|--------------------------------------------------------------------|
| 422      | Нет параметра `account_id`, он не число, или `limit` вне диапазона 1–100      | `{"detail": "account_id is required", "field": "account_id"}`      |
| 404      | Клиента с таким `account_id` нет                                             | `{"detail": "account 42 not found"}`                               |

## Как менять договорённость

Любое изменение этого документа вносится только через запрос на внесение
изменений (pull request) с обсуждением. Поведение сервиса и тесты обязаны
соответствовать последней версии этого файла.
